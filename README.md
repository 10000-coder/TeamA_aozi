# TeamA_aozi

> Frontend clone of [aozi.family](https://www.aozi.family/) built with React + Vite + Tailwind CSS.

## 🛠 Tech Stack
- **Framework**: React 18 / 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS / Lucide React
- **Mock Data**: Realistically structured mock data for token launches, graduation milestones, and social feed

## 🚀 Getting Started
```bash
npm install
npm run dev
```
